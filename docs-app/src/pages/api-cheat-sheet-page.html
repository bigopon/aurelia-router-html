Declare routes

Place routing behavior on the template branch it controls.

<au-route
  path="products/:id"
  exact
  title.bind="product.name"
  loading.bind="() => loadProduct()"
  loaded.bind="() => productReady()"
  can-load.bind="() => canOpenProduct()"
  can-unload.bind="() => canLeaveProduct()"
  on-error.bind="failure => recover(failure)"
  guard-failure="local"
  swap-order="parallel"
  animate>
  ...
</au-route>
AttributePurpose
pathStatic route pattern. Dynamic values use path.bind, path.to-view, or :path.
exactRequire the route to consume the complete path supplied by its parent.
fallbackParticipate only when no regular sibling matches.
redirect-toRedirect without rendering this route. Use redirect-mode="push" to retain the source history entry.
titleContribute static or bound metadata to the composed document title.
loading / loadedPrepare before activation or observe the completed nested branch.
can-load / can-unloadApprove or cancel navigation. can-load may also redirect.
guard-failureUse navigation for atomic cancellation or local to rematch a sibling fallback.
on-errorHandle loading or activation failures at the nearest route boundary.
swap-orderAttach first, detach first, or swap sibling views in parallel.
animateOpt this route into configured transition classes.

Path patterns

SyntaxMeaning
products, ./productsEquivalent contextual route declaration patterns.
path="/", path=".", path="./"The current parent index in an au-route declaration.
:id, :id?Required and optional named parameters.
*Consume and capture one segment as $params['*'].
files/**Consume every remaining segment as $params['**'].
au-link="/products"Start link and navigation resolution at the root context. Route declarations themselves remain contextual.

Links and navigation

Use au-link for application links and the context methods when markup or application logic needs direct control.

<!-- Relative to the current route context -->
<a au-link="reviews">Reviews</a>
<a au-link="./reviews">Reviews, explicitly relative</a>
<a au-link=".">Current context index</a>

<!-- Absolute from the root route context -->
<a au-link="/products">All products</a>
<a au-link="/">Application root</a>

<a au-link="guide#api">Guide API</a>
<a au-link.bind="{
  target: '/products/:id',
  params: { id: product.id },
  options: { exact: true },
  activeClass: 'selected'
}">
  Product
</a>

<a
  href.bind="$route.href('reviews')"
  class.bind="$route.isActive('reviews') ? 'is-active' : ''">
  Low-level link
</a>

A target without a leading slash is contextual. Its ./ form is equivalent. A leading slash is root-absolute for au-link, $route.href(), and $route.load(). In contrast, every au-route path declaration matches the residue supplied by its parent, even when its pattern starts with a slash.

const href = route.href(target, params, options);
const active = route.isActive(target, params, {
  exact: true,
  matchQuery: true,
  matchHash: true
});
await route.load(target, params, {
  query: { sort: 'recent' },
  hash: 'comments',
  replace: true
});
const paths = route.getPaths();

Route context and scoped URL state

Template APIValue
$routeThe nearest IRouteContext.
$paramsParameters captured by this route only.
$queryRead-only query values with get, getAll, has, and toString.
$hashThe route fragment without #.
$route.parent / root / childrenTraverse the declarative route tree.
$route.pattern / fullPathThe local pattern and its composed ancestor pattern.
$route.$path / residueThe path presented to this context and the portion left for children.
$route.active / titleCurrent match state and normalized route title.
$route.failureThe local recovery failure, including error, phase, source, boundary, recovery context, and abort signal.
 
import { resolve } from '@aurelia/kernel';
import { IRouteContext } from 'aurelia-v2-router-html';

export class ProductPage {
  private readonly route = resolve(IRouteContext);

  public openReviews(): boolean | Promise<boolean> {
    return this.route.load('reviews');
  }
}

Callback results

CallbackSupported result
loading / loadedvoid or Promise<void>.
can-loadApprove, return false, or return a contextual/root redirect result.
can-unloadApprove or return false to keep the current route active.
on-errorReturn nothing to bubble, return a redirect, or return { recover: 'local' }.

Bind callbacks as functions, for example loading.bind="() => load()". Aurelia v2 does not use .call here.

Configure the host integration

Routing.customize({
  routingMode: 'path', // 'path' | 'hash' | 'query'
  routeQueryKey: 'app',
  interceptLinks: true,
  swapOrder: 'parallel',
  animations: {
    enabled: true,
    classPrefix: 'au-route',
    fallbackMs: 400
  },
  titles: {
    separator: ' | ',
    fallback: 'Store'
  },
  scrolling: {
    behavior: 'smooth',
    block: 'start'
  }
});

Supply adapter or adapterFactory for memory, WebView, SSR, or host-specific locations. Plain links need interceptLinks for client-side navigation; au-link does not.
