Params

Keep parameters local to the route that declared them while nested views reach ancestors explicitly.

Syntax

<au-route path="users/:userId">
  Parent: ${$params.userId}
  <au-route path="posts/:postId">
    Child: ${$params.postId}
    Parent from child: ${$route.parent.$params.userId}
  </au-route>
</au-route>

Meaning

Each au-route creates its own parameter scope. The parent view receives userId; the nested view receives postId. Child $params does not silently merge ancestor parameters.

Apply it

Read local values from $params. When a nested view intentionally needs an ancestor value, follow its route context with $route.parent.$params.
