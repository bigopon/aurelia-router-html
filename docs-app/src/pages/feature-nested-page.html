Nested Routes

See how a parent route keeps its layout visible while nested views change.

Syntax

<a href.bind="$route.href('/logs')">Logs</a>
<span repeat.for="path of $route.getPaths(false)">${path}</span>

Meaning

$route.href('/logs') finds the registered descendant pattern and adds the current context's complete parent path. Active parameters are reused automatically. Pass a parameter object as the second argument when values come from application data, or pass $params when links must react to parameter changes without remounting the parent view.

Apply it

Call getPaths() on any route context for its current registered subtree, or use $route.root.getPaths() for the complete registry. Pass false to omit the context itself.
