Nested Routes

See how a parent route keeps its layout visible while nested views change.

Syntax

<au-route path="products/:productId">
  <a au-link=".">Overview</a>
  <a au-link="reviews">Reviews</a>

  <au-route path=".">Product overview</au-route>
  <au-route path="reviews">Product reviews</au-route>
</au-route>

Meaning

$route is the context of the nearest active au-route. It knows that route's local pattern, complete registered path, parameters, remaining URL, parent, children, and root context.

Apply it

Build links from registered route contexts instead of repeating full URLs. Active parameters are reused automatically, while an explicit parameter object can generate links for application data that is not currently active.

Build local and index links

<a au-link=".">Current section</a>
<a au-link="reviews">Reviews</a>
<a au-link="./reviews">Reviews for this product</a>

. targets the current section's index route. reviews and ./reviews are equivalent descendant targets and inherit active ancestor parameters.

Build a link from anywhere

<a href.bind="$route.root.href(
  'products/:productId/reviews',
  { productId: product.id }
)">Read reviews</a>

Start from $route.root when the target is outside the current subtree. Supply values for route parameters that are not available from the active context.

Read the current match

<p>Local pattern: ${$route.pattern}</p>
<p>Complete pattern: ${$route.fullPath}</p>
<p>Path at this level: ${$route.$path}</p>
<p>Remaining path: ${$route.residue}</p>
<p>Product: ${$route.$params.productId}</p>

pattern is local to the route, while fullPath combines its ancestors. $path is the URL portion presented at this level, and residue is the portion left for child routes.

Move through the route tree

<a au-link="specs">Sibling specs</a>
<span repeat.for="path of $route.getPaths(false)">${path}</span>
<span repeat.for="path of $route.root.getPaths()">${path}</span>

A relative target resolves inside the current route subtree and inherits its active parameters. getPaths() returns the registered subtree; pass false to omit the current context, or start at root to inspect the complete route registry.
