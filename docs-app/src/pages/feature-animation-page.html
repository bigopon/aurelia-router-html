Animations

Opt routes into transition choreography today with one route-level animate API, with CSS and callback forms settling from real completion plus bounded fallback.

Syntax

<au-route path="details" animate>
  ...
</au-route>

animate is route-level animation entry point. Bare animate attributes signals default CSS-class based animation, while other strings, callback, and object forms get normalized into internal descriptor.

Value shapes

<au-route path="a" animate>
<au-route path="b" animate="fade">
<au-route path="c" animate.bind="animateRoute">
<au-route path="d" animate.bind="{ kind: 'css', name: 'fade' }">
<au-route path="e" animate.bind="{ kind: 'js', run: animateRoute }">

One route-level animate property accepts multiple value shapes. CSS remains the low-friction path; callback animation is the stronger primitive for exact completion and cancellation.

CSS-driven routes now settle from real transitionend and animationend events, with a bounded fallback timer only as the safety net when the browser never delivers those events.

The route-owned settlement callback lives on its own page as transition-end.bind, because settlement is related to animation but is not itself an animation strategy.

Settlement

Route animation settlement is part of the shipped contract. Callback animation settles from the returned promise, CSS animation settles from real end events, stale work aborts when navigation is superseded, and bounded fallback timing prevents a route from hanging forever when completion signals never arrive.

Callback shape

public animateRoute = ({ direction, elements, signal }) => {
  const element = elements[0];
  if (element == null) return;

  const animation = element.animate(
    direction === 'enter'
      ? [{ opacity: 0, transform: 'translateY(18px)' }, { opacity: 1, transform: 'translateY(0)' }]
      : [{ opacity: 1, transform: 'translateY(0)' }, { opacity: 0, transform: 'translateY(-18px)' }],
    { duration: 180, easing: 'ease-out', fill: 'both' }
  );

  signal.addEventListener('abort', () => animation.cancel(), { once: true });
  return animation.finished.then(() => undefined, () => undefined);
};

Callback animation receives the route direction, animated elements, and an abort signal. Returning a promise gives the router an exact completion point, while superseding navigation aborts the stale callback path.

Reduced motion

@media (prefers-reduced-motion: reduce) {
  .animated-stage > .au-route-enter-active,
  .animated-stage > .au-route-leave-active {
    transition-duration: 1ms;
    transform: none;
  }
}

Reduced motion is part of the router-supported transition story. CSS can still express the visual variant directly, and callback-based animation can branch on the same reduced-motion-aware contract.
