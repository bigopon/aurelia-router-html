Exact, Fallback & Wildcard Paths

Control complete matches, no-match recovery, and routes that capture one or every remaining URL segment.

Syntax

<au-route path="settings" exact>...</au-route>
<au-route path="products/:id" exact>ID required</au-route>
<au-route path="offers/:id?" exact>ID optional</au-route>
<au-route path="*" fallback>
  <au-route path="details" exact>...</au-route>
</au-route>
<au-route path="folders/*" exact>
  Folder: ${$params['*']}
</au-route>
<au-route path="files/**">
  Path presented: ${$route.$path}
  Terminal segment: ${$params['**']}
  Residue after **: ${$route.residue}
  <au-route path="/" exact>Remaining URL is /</au-route>
</au-route>

Meaning

exact requires a route to consume all residue supplied by its parent. :id requires a segment, while :id? makes that segment optional. fallback marks a candidate the parent selects only when no regular sibling matches. * consumes one segment and exposes it as $params['*']. A terminal ** consumes the complete remaining residue, exposes it as $params['**'], and gives its children /.

Add exact where extra child segments must not be accepted. Add ? only when a named parameter may be omitted. Use fallback for a branch that appears only after regular siblings miss. Use * for one captured segment and end a path with ** when that route should terminally own every remaining segment. Captures are decoded and scoped to the route that declares them. Leading-slash forms /* and /** are equivalent to * and **.
