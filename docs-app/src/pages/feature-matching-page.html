Exact & Fallback

Keep prefix routing flexible while making complete matches and not-found branches explicit.

Syntax

<au-route path="/settings" exact>...</au-route>
<au-route path="*" fallback>
  <au-route path="/details" exact>...</au-route>
</au-route>
<au-route path="**">Consume the complete residue</au-route>

Meaning

exact requires a route to consume all residue supplied by its parent. fallback marks a candidate the parent selects only when no regular sibling matches. * consumes one segment and forwards the rest; ** consumes the complete residue.

Apply it

Add exact where extra child segments must not be accepted. Use * when nested routes need the remaining URL, or ** for a terminal catch-all whose children should receive /. Leading-slash forms /* and /** are equivalent.
