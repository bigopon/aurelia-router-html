Exact & Fallback Matching

Decide whether a route accepts child residue and what renders when every regular sibling misses.

Syntax

<au-route path="settings" exact>...</au-route>
<au-route path="products/:id" exact>ID required</au-route>
<au-route path="offers/:id?" exact>ID optional</au-route>
<au-route path="*" fallback>
  <au-route path="details" exact>...</au-route>
</au-route>

Meaning

exact requires a route to consume all residue supplied by its parent. :id requires a segment, while :id? makes that segment optional. fallback marks a candidate the parent selects only when no regular sibling matches in that parent context.

group is separate from matching modifiers: it creates a structural parent for descendant routes and therefore does not combine with path, exact, fallback, or redirect-to.

Apply it

<a au-link="products/camera">Camera</a>
<a au-link.bind="{ target: 'offers', options: { exact: true } }">Offers</a>

Add exact where extra child segments must not be accepted. Add ? only when a named parameter may be omitted. Use fallback for a branch that appears only after regular siblings miss.
