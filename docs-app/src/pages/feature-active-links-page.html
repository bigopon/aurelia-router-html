Active Links

Generate a link and its selected state from the same registered route target.

Syntax

<a au-link="reviews">Reviews</a>
<a au-link="./reviews">Reviews</a>
<a au-link="/products">All products</a>

Meaning

reviews and ./reviews resolve below the current route context. A leading slash starts from the root route context. The attribute generates href, uses $route.isActive() to toggle is-active, and applies exact aria-current automatically.

<a
  href.bind="$route.href('reviews')"
  class.bind="$route.isActive('reviews') ? 'is-active' : ''">
  Reviews without au-link
</a>

Apply it

Pathname matching is the default. Enable query or hash comparison only when that URL state represents a distinct navigation choice.

<a au-link.bind="{
  target: 'reviews',
  params: { productId: product.id },
  options: {
    query: { sort: 'recent' },
    matchQuery: true
  },
  activeClass: 'selected'
}">
  Recent reviews
</a>
