Active Links

Generate a link and its selected state from the same registered route target.

Syntax

<a
  href.bind="$route.href('/reviews')"
  class.bind="$route.isActive('/reviews') ? 'selected' : ''"
  aria-current.bind="$route.isActive('/reviews', {}, { exact: true }) ? 'page' : null">
  Reviews
</a>

Meaning

isActive() resolves registered targets exactly like href(). Prefix matching keeps a parent link selected on deeper pages; exact limits selection to one complete pathname.

Apply it

Pathname matching is the default. Enable query or hash comparison only when that URL state represents a distinct navigation choice.

$route.isActive('/reviews', {}, {
  query: { sort: 'recent' },
  matchQuery: true,
  hash: 'comments',
  matchHash: true
});
