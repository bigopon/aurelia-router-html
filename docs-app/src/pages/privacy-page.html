Privacy and analytics

This documentation site uses Google Analytics only when you choose to allow analytics.

Analytics choice

Choosing “Accept analytics” loads Google Analytics to help understand aggregate documentation usage. Choosing “Reject” keeps Google Analytics disabled.

Your choice is stored only in this browser so the site can remember it.

More information

Google explains how it handles analytics information in its Privacy Policy.

For a privacy question or to report a problem with this site, open a GitHub issue.
