Snapshots

Produce a snapshot of matches and branches from the current active routes.

Syntax

import { resolve } from '@aurelia/kernel';
import { IRouteContext } from 'aurelia-router-html';

export class ReportsPage {
  private readonly route = resolve(IRouteContext);

  public logActiveBranch(): void {
    const snapshot = this.route.getActiveSnapshot();
    console.log(snapshot.path);
    console.log(snapshot.matches.map(match => match.fullPath));
    console.log(snapshot.branches.paths);
    console.log(snapshot.branches.uniquePaths);
  }
}

Meaning

getActiveSnapshot() returns the last committed route state for the current router or route context subtree. The snapshot is immutable and keeps two views of the same state: matches is the flat set of active route snapshots, while branches exposes branch-shaped route snapshots, branch-shaped full paths, and precomputed unique full paths.

This matters because Router HTML does not model the active UI as one linear chain. Pathless groups, repeated structures, local fallback recovery, and sibling matches can produce multiple active branches at once.

Apply it

Use the flat matches collection when you need a compact list for diagnostics, titles, analytics, or inspection tools. Use branches when the distinction between parallel active branches matters.

const snapshot = this.route.getActiveSnapshot();

const leaves = snapshot.branches.routes.map(branch => branch.at(-1)?.fullPath);
const branchPaths = snapshot.branches.paths;
const uniquePaths = snapshot.branches.uniquePaths;
const activePatterns = snapshot.matches.map(match => match.fullPath);
const currentParams = snapshot.matches.at(-1)?.params ?? {};

Calling getActiveSnapshot() on a nested IRouteContext roots the result at that subtree. The returned path is the path visible to that context rather than the application root path.
