Routing that stays close to your HTML

Router HTML gives Aurelia applications composable routes, nested layouts, precise matching, and polished transitions directly in markup.

Register Router HTML and start routing

Register one configuration with the Aurelia application, then declare routes and links directly in its templates.

import Aurelia from 'aurelia';
import { Routing } from 'aurelia-v2-router-html';
import { App } from './app';

void Aurelia
  .register(Routing)
  .app({
    host: document.querySelector('#app'),
    component: App
  })
  .start();

Router HTML uses pathname URLs by default. Start with the examples below, then choose a different URL mode or adapter only when the host requires one.

Choose how routing integrates with the host

Route templates stay the same while configuration selects the URL strategy, navigation behavior, and location adapter. Path, hash, and query modes are ready-made browser adapter strategies; memory and custom adapters replace the browser boundary.

Behavior options

OptionControls
interceptLinksOpt into client-side handling for plain same-origin <a href> links. au-link does not require it.
swapOrderWhether incoming and outgoing sibling views attach first, detach first, or run in parallel.
animationsGlobal route-transition behavior; animation remains opt-in by default.
titlesBrowser title composition, fallback text, and custom formatting for active nested routes.

routeQueryKeyThe query-string key used by query routing mode; it defaults to app.

Copy the URL mode your host needs

Each configuration is complete on its own. Pathname is the default; hash and query-key modes keep the same route templates while changing the browser URL.

Pathname
/products/ice-cream 
Routing.customize({
  routingMode: 'path'
});
Hash
#products/ice-cream 
Routing.customize({
  routingMode: 'hash'
});
Query string
?app=products/ice-cream 
Routing.customize({
  routingMode: 'query',
  routeQueryKey: 'app'
});

Optional behavior shared by every URL mode

Routing.customize({
  // Optional: enhance eligible plain <a href> links.
  interceptLinks: true,
  swapOrder: 'parallel',
  animations: true,
  scrolling: {
    behavior: 'smooth',
    block: 'start'
  }
});
