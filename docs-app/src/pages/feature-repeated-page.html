Repeated Routes

Add routes from repeated data and see each generated URL become available immediately.

Dynamic path syntax

<au-route path.bind="item.path">...</au-route>
<au-route path.to-view="item.path">...</au-route>
<au-route :path="item.path">...</au-route>

Dynamic paths must use path.bind, path.to-view, or the :path shorthand. A plain path="${item.path}" resembles a static route during route registration and produces a development warning.
