Swap Order

Coordinate sibling views with predictable sequential or parallel transitions.

Syntax

<au-route path="/workspace" swap-order="parallel">
  <au-route path="/alpha">...</au-route>
  <au-route path="/beta">...</au-route>
</au-route>

Meaning

swap-order belongs to the parent route because that context coordinates its outgoing and incoming children. parallel starts both operations in the same pass.

Apply it

Use parallel for overlapping transitions, the default attach-next-detach-current to avoid an empty stage, or detach-current-attach-next when teardown must finish first.
