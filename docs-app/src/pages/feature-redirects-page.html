Declarative Redirects

Move legacy URLs, choose branch defaults, and recover unmatched locations without rendering an intermediate view.

Syntax

<au-route
  path="legacy/:productId"
  exact
  redirect-to="/products/:productId">
</au-route>

The redirect route matches normally, passes its captured parameters into the target, and renders no content of its own.

Relative and absolute targets

<au-route path="account">
  <au-route path="/" exact redirect-to="profile"></au-route>
  <au-route path="profile" exact>Profile</au-route>
</au-route>

<au-route path="old-account" redirect-to="/account/profile">
</au-route>

profile resolves from the redirect route's parent context, producing /account/profile. A leading slash resolves from the root route context.

Relative redirects with query and hash

<au-route path="area">
  <au-route path="workspace">
    <au-route
      path="private/:id"
      exact
      redirect-to="../login?from=private#warning">
    </au-route>
  </au-route>

  <au-route path="login" exact>Login</au-route>
</au-route>

The redirect target still resolves from the redirect route's parent context. In this example, ../login?from=private#warning climbs from /area/workspace/private/:id to the parent branch and becomes /area/login?from=private#warning.

Dynamic targets

<au-route
  path="legacy/:productId"
  redirect-to.bind="legacyTarget">
</au-route>

<au-route path="seasonal" :redirect-to="campaignTarget">
</au-route>

Dynamic redirects require redirect-to.bind, redirect-to.to-view, or :redirect-to. Interpolation-looking static values produce a development warning, just like dynamic paths.

Fallback redirects

<au-route path="not-found" exact>
  <h1>Page not found</h1>
</au-route>

<au-route
  path="*"
  fallback
  redirect-to="/not-found">
</au-route>

The fallback redirects only after every regular sibling route misses. The destination must be a regular sibling so it wins instead of matching the fallback again.

History and loop safety

<!-- Replacement is the default. -->
<au-route path="legacy" redirect-to="/current"></au-route>

<!-- Opt into an additional history entry. -->
<au-route
  path="offer"
  redirect-to="/sale"
  redirect-mode="push">
</au-route>

Replacement prevents Back from immediately revisiting the redirect source. Push mode is available for intentional history steps. Redirect chains track normalized locations and throw a development-friendly error when a location repeats.
