Programmatic Navigation

Navigate from application logic with the same route context used by au-link and template $route.

Syntax

import { resolve } from '@aurelia/kernel';
import { IRouteContext } from 'aurelia-v2-router-html';

export class ProductPage {
  private readonly route = resolve(IRouteContext);

  public openReviews(): void {
    this.route.load('reviews');
  }
}

Meaning

IRouteContext is the view-model form of template $route. Aurelia resolves the context nearest to the component: root components navigate from the root, while components rendered inside an au-route navigate relative to that branch.

TargetResult
reviews or ./reviewsResolve below the injected route context.
/products/:idResolve from the root and fill required parameters.
A registered IRouteContextNavigate directly to that route context.

Apply it

public openProduct(id: string): void {
  this.route.load('/products/:id', { id });
}

public openRecentReviews(id: string): void {
  this.route.load(
    '/products/:id/reviews',
    { id },
    {
      query: { sort: 'recent' },
      hash: 'comments'
    }
  );
}

public replaceWithLogin(): void {
  this.route.load('/login', {}, { replace: true });
}

The third argument uses the same query and hash options as $route.href(). Set replace when the new location should replace the current history entry. Application code does not need IRouteCoordinator or a path adapter.

<button click.trigger="$route.load('/login')">
  Sign in
</button>

Use au-link whenever an interaction represents a normal destination. Use load() when navigation follows application logic, such as completing a workflow or selecting a result in code.
