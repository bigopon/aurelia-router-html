Page Titles

Describe each route where it is declared, then let the active nested tree produce one useful browser title.

Syntax

<au-route path="products" title="Products">
  <au-route
    path="camera"
    exact
    title.bind="cameraTitle">
    <h1>Camera</h1>
  </au-route>
</au-route>

Use title for fixed metadata. Dynamic values require title.bind, title.to-view, or :title.

Meaning

Every titled route in the active nested tree contributes one part. The default policy produces Products · Camera details in the editable example. Applications can instead select one title and append a fixed brand.

Apply it

Routing.customize({
  titles: {
    separator: ' — ',
    fallback: 'Example store'
  }
});

Browser pathname routing enables titles automatically. Set titles: false to opt out, or configure a separator, fallback, or custom compose function. A custom or memory adapter enables the browser title layer explicitly with titles: true or an options object.
