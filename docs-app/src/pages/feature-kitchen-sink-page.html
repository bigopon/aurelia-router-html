Kitchen Sink

Build a tiny playroom app by mixing normal Aurelia templates with a declarative route tree.

Syntax

<template repeat.for="room of rooms">
  <au-route path.bind="'/demo/' + room.id">
    <let base.bind="'/features/kitchen-sink/demo/' + room.id"></let>
    <kitchen-shell title.bind="room.name">
      <strong au-slot="heading">${room.name}</strong>
      <template repeat.for="page of room.pages">
        <au-route path.bind="'/' + page.id" exact>${page.label}</au-route>
      </template>
    </kitchen-shell>
  </au-route>
</template>

Meaning

Routes use the same scopes as the surrounding Aurelia template. Room and page repeat items, <let> variables, VM properties, bindings, and projected slots all remain available inside matched branches.

Apply it

Keep each route beside the markup it controls. Generate routes from data when the choices come from a list, and use ordinary slotted components for reusable page shells.
