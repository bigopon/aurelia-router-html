Kitchen Sink

Build a tiny playroom app by mixing normal Aurelia templates with a declarative route tree.

Syntax

<template repeat.for="room of rooms">
  <au-route path.bind="room.path">
    <let greeting.bind="'Welcome to ' + room.name"></let>
    <room-shell room.bind="room">
      <strong au-slot="title">${greeting}</strong>
    </room-shell>
  </au-route>
</template>

Meaning

Routes use the same scopes as the surrounding Aurelia template. Repeat items, <let> variables, VM properties, bindings, and projected slots remain available inside matched branches.

Apply it

Keep each route beside the markup it controls. Generate routes from data when the choices come from a list, and use ordinary slotted components for reusable page shells.
